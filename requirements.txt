# torch: install the wheel variant matching your NVIDIA DRIVER's supported
# CUDA version, NOT the newest. A bare `pip install torch` pulls the latest
# CUDA build (e.g. cu13x), which fails with "driver too old" on <=12.9
# drivers (torch.cuda.is_available() -> False and every kernelbench task
# silently scores as failed). Example for a 12.8/12.9 driver:
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
# Check the driver's max supported CUDA with `nvidia-smi`.
torch
