Write a function `void compute_eigenvalues_and_vectors(...)` that demonstrates
the usage of the cuSOLVER library to compute the eigenvalues and right
eigenvectors of a complex matrix using `cusolverDnXgeev`. The function should:
- Accept a complex matrix `A` of size `n x n` in column-major order.
- Store the eigenvalues in `W` (size `n`) and the eigenvectors in `VR` (size `n x n`).
- Accept host data and handle all device memory allocation, data transfers, and cleanup internally.

Function signature:
```cpp
void compute_eigenvalues_and_vectors(int64_t n, const std::vector<cuDoubleComplex>& A,
                                     std::vector<cuDoubleComplex>& W,
                                     std::vector<cuDoubleComplex>& VR);
```

Your implementation should be placed in `solution.cu` and use the declarations from `include/cusolver_eigen.h`.
