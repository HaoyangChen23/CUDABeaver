symmetric matrix using `cusolverDnXsyevd`. The function should
- Accept the matrix size `m`, input matrix `A` (row-major), and output arrays

- Accept host data and handle all device memory allocation, data transfers, and
  cleanup internally.

```cpp
void compute_eigen_decomposition(int m, const std::vector<double>& A,
                                 std::vector<double>& W, std::vector<double>& V);
```

The contract is provided in `include/eigen_decomposition.h`.
