Write a function to compute the cumulative distribution function (CDF) of grayscale images using the CUDA Thrust library. The pixel values of the image range from 0-255. The function should sort the pixel values, calculate their histogram, derive the CDF, and then map each pixel to its CDF value.

Implement the function with the following signature declared in `include/cdf_calculator.h`:

```cpp
void calculatePixelCdf(thrust::device_vector<int> &srcImage, int size, cudaStream_t stream, thrust::device_vector<float> &output);
```

Where:
- `srcImage` is a reference to the input image matrix of type thrust device_vector<int>
- `size` is the total number of pixels in the input image
- `stream` is the CUDA stream for asynchronous execution
- `output` is a reference to the CDF of each pixel of type thrust device_vector<float>

Example usage:
```
calculatePixelCdf({61, 112, 91, 176, 134, 154, 32, 68, 84, 163, 31, 58, 135, 162, 163, 52}, 16, stream, output)
→ output: {0.3125, 0.5625, 0.5, 1, 0.625, 0.75, 0.125, 0.375, 0.4375, 0.9375, 0.0625, 0.25, 0.6875, 0.8125, 0.9375, 0.1875}

calculatePixelCdf({18, 171, 45, 34, 239, 61, 73, 52, 82, 57, 245, 228, 102, 31, 205, 193}, 16, stream, output)
→ output: {0.0625, 0.6875, 0.25, 0.1875, 0.9375, 0.4375, 0.5, 0.3125, 0.5625, 0.375, 1, 0.875, 0.625, 0.125, 0.8125, 0.75}
```
