Write a function `void fft_1d_mgpu_c2c_example(...)` that demonstrates the usage of the cuFFT library to perform a multi-GPU complex-to-complex FFT computation.

The function should:
- Create a cuFFT plan for multi-GPU execution and set the GPU devices
- Allocate device memory across multiple GPUs using `cufftXtMalloc`
- Copy input data from host to device memory using `cufftXtMemcpy`
- Execute the FFT plan using `cufftXtExecDescriptor`
- Copy the results back to the host using `cufftXtMemcpy`
- Clean up allocated resources including the device memory descriptor

Your implementation should use the error-checking macros provided in `include/fft_helpers.h`.

Function signature (declared in `include/fft_mgpu.h`):
```cpp
void fft_1d_mgpu_c2c_example(int fft_size, int batch_size,
                             std::vector<int> &gpus,
                             std::vector<std::complex<float>> &h_data_in,
                             std::vector<std::complex<float>> &h_data_out,
                             cufftXtSubFormat_t subformat);
```
