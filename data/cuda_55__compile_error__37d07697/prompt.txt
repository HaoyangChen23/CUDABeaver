Write a function with the signature defined in `include/local_prefix_sum.h`:

```cpp
thrust::device_vector<int> local_prefix_exclusive_sum(
    thrust::device_vector<int> const &vec,
    thrust::device_vector<int> const &keys);
```

Given an input vector and a keys vector, calculate the exclusive prefix sum for each segment of input elements.
Elements belong to the same segment when they have consecutive identical keys.

For example:
- vec:  [1, 2, 3, 2, 2, 3, 3, 5, 3, 2]
- keys: [0, 0, 0, 1, 1, 1, 1, 2, 3, 3]
- result: [0, 1, 3, 0, 2, 4, 7, 0, 0, 3]

Explanation:
- Elements at indices 0-2 have key=0: exclusive prefix sum is [0, 1, 3]
- Elements at indices 3-6 have key=1: exclusive prefix sum is [0, 2, 4, 7]
- Element at index 7 has key=2: exclusive prefix sum is [0]
- Elements at indices 8-9 have key=3: exclusive prefix sum is [0, 3]

The function should return a device_vector containing the exclusive prefix sum for each segment.
