Write a function `void compute_svd(...)` that demonstrates the usage
of the cuSOLVER library to compute the Singular Value Decomposition (SVD)
of a matrix `A` using `cusolverDnXgesvdp`. The function should
- Update `A` in-place and store the singular values in `S`, the left singular
  vectors in `U`, and the right singular vectors in `V`.
- Accept host data and handle all device memory allocation, data transfers, and
  cleanup internally.

Function signature:
```
void compute_svd(int m, int n, std::vector<double> &A, std::vector<double> &S,
                 std::vector<double> &U, std::vector<double> &V,
                 double &h_err_sigma);
```

Your solution should include the header `include/compute_svd.h` which contains the function declaration and required macros.
