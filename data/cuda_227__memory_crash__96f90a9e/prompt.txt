Write a CUDA kernel to sort segments of an array independently by utilizing intra-warp thread communication. For simplicity, assume only equally sized segments of up to 128 elements are used. Ensure that an arbitrary number of threads per block functions correctly.

The kernel signature is defined in `include/k_sortSegments.h`:

```cpp
__global__ void k_sortSegments(float *array_d, float *arrayOut_d, int segmentSize, int arraySize);
```

Where:
- `array_d` is a pointer to the array containing multiple segments to be sorted
- `arrayOut_d` is a pointer to the array with sorted segments
- `segmentSize` represents the number of elements in each segment
- `arraySize` indicates the total number of elements in the array
