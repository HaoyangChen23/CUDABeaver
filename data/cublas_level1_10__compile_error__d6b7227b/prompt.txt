Write a function `void cublas_rotm_example(...)` that demonstrates the usage of
the cuBLAS library to perform a modified Givens rotation operation using
`cublasDrotm`. The function should accept host data and handle all device memory
allocation, data transfers, and cleanup internally.

Your implementation should follow the function signature defined in `include/cublas_rotm.h`:
```cpp
void cublas_rotm_example(int n, std::vector<double> &A, std::vector<double> &B,
                         const std::vector<double> &param);
```

Use the error-checking macros provided in `include/cuda_helpers.h` to handle CUDA and cuBLAS errors.
