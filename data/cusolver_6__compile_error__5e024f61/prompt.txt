Write a function `void lu_factorization(...)` that demonstrates the usage of the cuSOLVER library to perform LU factorization of a matrix `A` using `cusolverDnDgetrf`.

This function should accept host data and handle all device memory allocation, data transfers, and cleanup internally.

The function signature is declared in `include/lu_factorization.h`:
```cpp
void lu_factorization(int m, const std::vector<double>& A, std::vector<double>& LU, std::vector<int>& Ipiv, int& info, bool pivot_on);
```

**Input/Output Data Format:**

The input matrix `A` and output matrix `LU` are stored as flat `std::vector<double>` in column-major order, following the standard BLAS/LAPACK convention that cuSOLVER expects.
For an m×m matrix stored in a vector, element at index `[i + j*m]` corresponds to row i and column j (both 0-indexed).

The pivot indices returned by cuSOLVER follow the LAPACK convention (1-based indexing).

**Requirements:**

Your implementation must use the cuSOLVER library with the appropriate function for double-precision LU factorization. The function should handle all necessary device operations internally and ensure proper resource management with no memory leaks.

The `pivot_on` parameter controls whether pivoting is enabled: when true, perform factorization with pivoting; when false, disable pivoting.
