Write a function `void dense_to_sparse_blocked_ell(...)` that demonstrates
usage of the cuSPARSE library to convert a dense matrix to a sparse matrix in
Blocked ELL format using `cusparseDenseToSparse_convert`. This function should
accept host data and handle all device memory allocation, data transfers, and
cleanup internally.

The function signature is declared in `include/dense_to_sparse.h`:
```cpp
void dense_to_sparse_blocked_ell(int num_rows, int num_cols, int ell_blk_size,
                                 int ell_width,
                                 const std::vector<float> &h_dense,
                                 const std::vector<int> &h_ell_columns,
                                 std::vector<float> &h_ell_values);
```

You may use the error-checking macros provided in `include/cusparse_helpers.h`.
