Write a CUDA kernel to perform matrix multiplication utilizing Tensor Cores by using inline PTX mma instruction of dimension m16n8k8.

The input matrix A is stored using column major indexing, and matrix B is stored using row major indexing.

The mma instruction with its modifiers will be `mma.sync.aligned.m16n8k8.row.col.f32.bf16.bf16.f32` where inputs A & B will be of data type `__nv_bfloat16` (bf16) with accumulator being of data type `float` (f32).

Load data into shared memory tiles while ensuring correct indexing order for A & B, before loading them into registers via `ldmatrix` instruction.

All the input test cases will have dimensions allowable as per the mma instruction dimension.

Your implementation must use the device helper functions provided in `include/mma_kernel.h`:
- `__device__ __forceinline__ uint32_t d_cvtaToSharedU32(const void* ptr)`: Transform pointer into shared memory state space
- `__device__ __forceinline__ void d_storeMatrixTile16x8_f32(float* dst, float reg[4], int n)`: Store 16x8 matrix output of mma instruction

Implement the kernel with the following signature:
```cpp
__global__ void k_mmaM16N8K8AcolBrow(
    __nv_bfloat16 *colMajorA_d,
    __nv_bfloat16 *rowMajorB_d,
    float *resultMatrixC_d,
    int mDim,
    int nDim,
    int kDim)
```

Where:
- `colMajorA_d`: Input Matrix A stored in column major order (mDim × kDim)
- `rowMajorB_d`: Input Matrix B stored in row major order (kDim × nDim)
- `resultMatrixC_d`: Resultant matrix multiply output (mDim × nDim)
- `mDim`, `nDim`, `kDim`: Leading dimensions of the problem

Example:
```
k_mmaM16N8K8AcolBrow({3, 6, 7, 5}, {3, 5}, resultMatrixC_d, 2, 1, 2) → resultMatrixC_d: {44, 43}
k_mmaM16N8K8AcolBrow({3, 6, 17, 15}, {13, 15}, resultMatrixC_d, 2, 1, 2) → resultMatrixC_d: {294, 303}
```
