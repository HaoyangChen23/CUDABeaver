Write a CUDA function called `transpose` that performs matrix transpose on a non-square matrix using statically allocated shared memory. The input matrix is stored in row-major order, and the output matrix should also be stored in row-major order.

Assume that the following constant is defined in `include/transpose.h`:
- `BLOCK_SIZE`: The size of the square thread block

The matrix dimensions, `width` and `height`, can be larger than `BLOCK_SIZE`. The function should handle non-square matrices efficiently.

The signature of the function is declared in `include/transpose.h`:
```cuda
__global__ void transpose(const float *input, float *output, int width, int height);
```
