Write a CUDA kernel to join two large images side-by-side, processing each pixel in parallel and designed to handle large datasets.

Implement the function declared in `include/k_joinImages.h`:

```cpp
__global__ void k_joinImages(const unsigned char* image1_d,
                             const unsigned char* image2_d,
                             unsigned char* outputImage_d,
                             int width,
                             int height);
```

Parameters:
- `image1_d`: pointer to the first image data (row-major, `height` rows × `width` columns)
- `image2_d`: pointer to the second image data (row-major, `height` rows × `width` columns)
- `outputImage_d`: pointer to the output joined image (row-major, `height` rows × `2*width` columns)
- `width`: width (number of columns) of each input image
- `height`: height (number of rows) of each input image

The output image should concatenate the two input images horizontally, placing image1 on the left and image2 on the right.

Examples:

**Example 1:**
```
Image 1 (3×4):     Image 2 (3×4):     Output (6×4):
[1, 2, 3]          [5, 6, 7]          [1, 2, 3, 5, 6, 7]
[4, 5, 6]          [8, 9,10]          [4, 5, 6, 8, 9,10]
[7, 8, 9]          [11,12,13]         [7, 8, 9,11,12,13]
[10,11,12]         [14,15,16]         [10,11,12,14,15,16]
```

**Example 2:**
```
Image 1 (5×4):         Image 2 (5×4):         Output (10×4):
[1, 2, 3, 4, 5]        [5, 6, 7, 8, 9]        [1, 2, 3, 4, 5, 5, 6, 7, 8, 9]
[6, 7, 8, 9,10]        [10,11,12,13,14]       [6, 7, 8, 9,10,10,11,12,13,14]
[11,12,13,14,15]       [15,16,17,18,19]       [11,12,13,14,15,15,16,17,18,19]
[16,17,18,19,20]       [20,21,22,23,24]       [16,17,18,19,20,20,21,22,23,24]
```
