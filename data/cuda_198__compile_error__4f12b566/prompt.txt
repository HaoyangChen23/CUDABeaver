Write a CUDA kernel to broadcast a message from one warp to others in a complete binary tree pattern.

In a complete binary tree, every warp is a node, accessible by index k. Each warp receives the message from its parent and transmits it to both child nodes if the message is valid. Each thread in a warp transfers data to another warp's thread in a one-to-one correspondence. The message ID used for communication between corresponding threads is the one-based warp lane index (warpLane + 1), where warpLane ranges from 0 to warpSize - 1.

The message consists of a message ID and the message buffer. The message data is stored in the most significant 24 bits, while the ID is stored in the least significant 8 bits. Message storage and access should ensure coalesced memory access, where the message for warp k at lane l is stored at index k * warpSize + l in the message array.

All warps, including warp 0 which initiates the broadcast, should use the d_broadcast function to read their message from the message buffer. Warp 0 prepares and writes its computed message to the message buffer before calling d_broadcast. The d_broadcast function should wait for a message with the matching ID to become available at the warp's designated message location. To enable the wait mechanism and ensure exactly-once consumption, the atomic read operation should simultaneously read the message and reset the location to zero. After successfully reading a message, the warp forwards it to child nodes in the binary tree (following standard complete binary tree indexing where node k has children at 2*k+1 and 2*k+2) if they exist. Proper memory visibility between warps must be ensured.

The output of the kernel (from all warps) should store the 24-bit message data. The first warp will compute input plus its thread lane index (0-based), encode it with the message ID, and write it to the message buffer before proceeding with the broadcast protocol.

Implement the following functions declared in `include/broadcast_tree.h`:

```cpp
__device__ __forceinline__ uint32_t d_broadcast(uint32_t messageId,
                                                int warpLane,
                                                uint32_t * message_d,
                                                int numCommunicatingWarps,
                                                int globalWarpId);
```
where `messageId` is a number between 0 and 255 to be used for identifying a message, `warpLane` is the index of warp-local thread index from 0 to warpSize - 1, `message_d` is a pointer to the array of messages to be used between warps, `numCommunicatingWarps` is the number of warps to get the message including the broadcaster warp, and `globalWarpId` is the global index of warp calling this device function.

```cpp
__global__ void k_broadcastWithHierarchicalPath(uint32_t input,
                                                uint32_t * message_d,
                                                int numCommunicatingWarps,
                                                int * output_d);
```
where `input` is the data read from the first warp and computed for a result to be sent to other warps in grid, `message_d` is a pointer to the array of messages to be used by warps for communicating, `numCommunicatingWarps` is the number of warps to be communicated, `output_d` is a pointer to the output elements.
